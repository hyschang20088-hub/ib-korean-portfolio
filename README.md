# IB DP 한국어 A 학습자 포트폴리오 (Younsang Chang · 장윤상)

이 저장소는 GitHub Pages로 공개되는 학습자 포트폴리오 사이트입니다.

## 파일 구성

- `index.html` — 사이트의 모양과 작동 방식 (보통 고칠 필요 없음)
- `entries.js` — 사이트에 보이는 모든 내용 (작품, 자료 목록)
- `images/` — 손노트, 시험지 등 사진
- `files/` — PDF 파일

## 새 자료 추가하기

1. `entries.js`를 엽니다 (GitHub에서 파일을 열고 연필 아이콘을 누르면 바로 고칠 수 있습니다).
2. `entries` 목록에서 비슷한 자료의 `{ ... },` 블록 하나를 복사해 붙여 넣습니다.
3. `id`(겹치지 않는 영문 이름), `section`, `works`, `title`, `date`, `type`, `links`를 바꿉니다.
4. 저장(Commit)하면 1~2분 뒤 사이트에 반영됩니다.

`section` 값: `works`(작품별 정리), `paper1`, `paper2`, `io`(구술 에세이), `exams`(시험지들)
